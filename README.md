# YouTube Clone Project
A simple YouTube clone that integrates the YouTube Data API to fetch video data dynamically. Built using HTML, CSS, JavaScript (with Fetch API), and Google Cloud services. This project allows users to interact with YouTube-like content, including video search, display, and playback functionality.

## Features

- **Video Search**: Fetch YouTube video data based on search terms using the YouTube Data API.
- **Video Display**: Display video thumbnails, titles, and descriptions dynamically.
- **Video Playback**: Play videos from the YouTube platform directly on your page.
- **API Integration**: Fetch video data from the YouTube Data API and display results using JSON and Fetch API.
- **Google Cloud**: Integrated with Google Cloud services for handling API requests.
  
## Technologies Used

- **HTML**: Structure of the page.
- **CSS**: Styling and layout of the page.
- **JavaScript (JS)**: Used for fetching API data, handling interactions, and updating the DOM.
- **Fetch API**: For making asynchronous API calls to retrieve YouTube data.
- **YouTube Data API**: Used to fetch video data from YouTube.
- **Google Cloud**: Handles API requests for YouTube Data API.

## Installation Instructions

### 1. Clone the Repository

### 2 . Obtain YouTube Data API Key
Go to the Google Cloud Console.
Create a new project and enable the YouTube Data API v3.
Navigate to the API & Services section and generate a new API key.

###3. Set Up Your API Key
Open the data.js file in the project.
Replace the placeholder API_KEY with your YouTube Data API key:
const API_KEY = 'YOUR_API_KEY_HERE';

### 4.  Open the Project in a Browser
Simply open the index.html file in a web browser to view the project.
Alternatively, you can host it on a local server or deploy it online.

### 5. /youtube-clone
  /index.html          # Main HTML file
  /styles.css          # Styling for the page
  /script.js           # JavaScript file with Fetch API logic
  /data.js             # Store API key and other config details
  /assets/             # Folder for images, icons, etc.
